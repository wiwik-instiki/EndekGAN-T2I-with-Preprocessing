# IEEE Access originality assessment and comparison discipline

**Main literature anchor:** TiPGAN (He et al., Computer-Aided Design, 2025) establishes image-conditioned tileable textile synthesis with patch-swapping/patch-tiling and the RTV score. Its published code does not accept an arbitrary text prompt. This is a *scope gap*, not a result showing TiPGAN is inferior.

**Additional literature comparator:** DF-GAN (Tao et al., CVPR, 2022) establishes text-conditioned generation; it does not target periodic edge continuity. The reproduced external comparison here is an **adapted DF-GAN–MiniLM**: official NetG/NetD/NetC blocks with a frozen 384-D multilingual MiniLM conditioning vector, **not canonical DAMSM DF-GAN**. It accepts text, but not the EndekGAN explicit class input; compare with caveat.

**Existing implementation:** EndekGAN-T2I V2 employs text and class conditioning with a seam regularizer on opposing boundary strips. This same family of conditioning and seam penalty already existed in the team's earlier EndekGAN repository. Source-aware splits and 336 crops are *evaluation/preprocessing contributions*, not proof of a newly invented neural network architecture.

**Measured trade-off:** Proposed seam-aware model has lower seam gap than an internal no-seam Transformer control, but worse mean pooled FID/KID and LPIPS diversity in a 37-reference held-out test. It cannot be claimed to outperform the control across quality dimensions. DF-GAN two held-out seeds have been observed; third remains unverified, so do not compute DF-GAN three-seed means. TiPGAN has only a 30-iteration compatibility pilot and no converged Endek baseline.

**Originality gate:** If an IEEE Access submission requires a strong new *architectural mechanism*, there is currently no independent implementation/ablation proving one beyond the earlier EndekGAN. A possible future mechanism would be prompt-conditioned periodic feature fusion with a class-aware boundary objective, but this is merely a hypothesis; do not put it in Proposed Method unless designed, implemented and evaluated with matched controls. A safer presently supported contribution is a controlled examination of the tileability–fidelity trade-off in text-conditioned Endek generation using source-independent preprocessing and three-seed reproducibility.

**Immediate blockers:** (1) complete and archive the seed2025 external DF-GAN held-out test; (2) finish a matched, properly converged TiPGAN image-conditioned texture protocol without test-image conditioning leakage; (3) independently validate prompt–image/crop semantics; (4) obtain blinded cultural and prompt fidelity evaluations from Endek experts on generated images; (5) examine dHash visually similar cross-split pair; (6) compare with current 2026 seamless-textile diffusion literature, e.g. DiCoT, in Related Work without pretending it was a trained baseline.
